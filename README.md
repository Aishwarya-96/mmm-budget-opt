# Marketing Mix Model & Budget Optimiser

> **Status: in progress.** No results are reported yet. Sections marked *TBD* are filled in as each stage is completed.

## The question

A brand spends across several media channels in many regions. It wants to know:

1. **What did each channel contribute to sales?**
2. **What is the return on each euro, per channel, with honest uncertainty?**
3. **With the same total budget, how should spend be split to maximise sales?**

This project answers those questions the way a measurement consultant would: check the data is fit for purpose, build a transparent baseline, fit Bayesian marketing mix models in [Google Meridian](https://developers.google.com/meridian), prove the models recover known effects before trusting them on real data, and turn the result into a budget recommendation.

## Approach

| Stage | What | Why |
|---|---|---|
| 1. Data readiness | Panel completeness, spend vs exposure, population, controls (`mmm.data_check`) | Decides whether ROI is directly measurable and which assumptions must be stated |
| 2. Baseline | Ridge regression on hand-written adstock + Hill saturation (`mmm.transforms`) | Transparent benchmark; shows the mechanics without a library |
| 3. Meridian, national | Bayesian MMM on totals across regions | Standard approach; ROI with credible intervals; priors encode business knowledge |
| 4. Meridian, geo | Hierarchical model across regions | Tests whether regional variation gives tighter, more plausible estimates |
| 5. Recovery validation | Fit all models on simulated data with planted effects (`mmm.simulate`) | Good fit does not imply correct ROI; recovery of known truth does |
| 6. Optimiser + app | Reallocate a fixed budget using fitted response curves; Streamlit front end | Turns model output into a decision a marketer can act on |

### Validation design

Real data has no ground truth, so model trust comes from simulation. `mmm.simulate` generates a weekly geo panel with known decay, saturation and effect size per channel, in two regimes:

- **Exogenous spend**: budgets are planned independently of sales.
- **Endogenous spend**: part of each week's spend reacts to last week's sales, as real budgets often do. This links spend to demand and is a common source of over-credited media.

Each model is scored on how closely it recovers the true ROI per channel in both regimes.

Meta Robyn's simulated weekly dataset is used separately as a **cross-framework comparison** (Meridian vs Robyn on the same data). It does not publish its generating parameters, so it is not used for recovery scoring.

## Data

- **Real:** Kaggle *Sample Media Spends Data* — weekly media and sales by division, Jan 2018 – Feb 2020. Not committed to the repo; download into `data/raw/`.
- **Synthetic:** generated by `python -m mmm.simulate` into `data/synthetic/`.

## Repo layout

  transforms.py   geometric adstock and Hill saturation
  simulate.py     known-truth geo panel generator (exogenous / endogenous spend)
  data_check.py   data-readiness report for a real dataset
tests/            unit tests for transforms and simulator
notebooks/        one notebook per stage

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .

pytest
python -m mmm.simulate                         # exogenous
python -m mmm.simulate --endogenous-share 0.4  # endogenous
python -m mmm.data_check data/raw/<file>.csv --geo <geo_col> --date <date_col> --kpi <sales_col>
```
